# Optional showcase content and credits

Original sample source/assets use [LICENSE.txt](../LICENSE.txt). The earlier basic images, HDR environment, animated mesh and WAV are generated by `tools/generate_sample_assets.py`. The showcase combines original industrial geometry/generated maps with the following CC0 scans, sand maps and photographic sky. Sample authoring tools live in `examples/showcase/tools`; engine builds do not need them.
