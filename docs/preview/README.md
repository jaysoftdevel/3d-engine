# Native renderer previews

SUNDOG stills are unretouched 1920x1080 framebuffer readbacks from the bundled engine. The MP4 is an eight-second montage of four two-second native offline captures, 960x540 at 24 capture frames per second. It has no audio track. These are functional visual evidence, not real-time performance benchmarks.

- sundog-rover.png: rover approach, wheel dust and steam.
- sundog-repair.png: drone repair, HDR sparks, hopper sand/gravel and cargo.
- sundog-relay.png: powered relay and outpost overview.
- sundog-preview.mp4: approach / cargo / repair / powered relay.
- graphics-lab.png: settings laboratory.

Render independently with the sample's --offscreen, --time, --frames, --capture and --sequence flags. This scene does not match Steel Nomad's production visual quality.
