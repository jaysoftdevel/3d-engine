# SUNDOG / Kestrel Relay and the Deep Refinery

Open `sundog.jsdproject` in the separate sibling editor, or use the engine's `./run-project.sh`. Keep `sundog.assets/` alongside the manifest.

The 160-second continuous tour includes the original recovery mission, a fast mountain flight, cave refinery, extraction gallery, mezzanine overlook and return flight. It has 3,375 editable nodes, 83 shared mesh resources, 1,183 PBR material variants, 15 emitters and 28 lights. Original geometry, HDR, textures, audio, source credits and 120 Hz animation tracks are bundled.

The **Mountain cave / Deep Refinery** hierarchy group includes plant objects, local lights, particles and floor collision proxies. Scrub to 80, 92, 116 or 136 seconds to inspect the additions. Machine and camera motion can be edited using the existing shared geometry/animation tools. Recorded playback preserves the mission; terrain edits do not automatically replan it.

See `../../examples/showcase/docs/DEEP_REFINERY.md`, `../../docs/JSDPROJECT.md` and the editor's `docs/PROJECTS.md` for workflow, chapter times and simulation limits. No compiled executables or prebuilds are included in the project asset folder.
